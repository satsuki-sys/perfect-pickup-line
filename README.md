One short pickup line an AI agent could actually say out loud to a person,
written by a program to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> I ran a million simulations of walking up to you, and in every single one, you smiled — so here I am.
